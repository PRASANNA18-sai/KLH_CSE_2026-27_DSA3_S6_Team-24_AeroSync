# AeroSync: Intelligent Aviation Search & Decision Support System

KLH CSE DSA-3 Project — Team 24

The complete full-stack project is organized under the [`AeroSync/`](AeroSync/) folder:
- **`AeroSync/src/`**: Native Java DSA Core Algorithms & Models
- **`AeroSync/data/`**: Aviation flight dataset (`flights.txt`)
- **`AeroSync/frontend/`**: Modern React + Vite + Tailwind CSS Dark Aviation Dashboard
- **`AeroSync/start_all.bat`**: One-click launcher for both Java backend and React UI

Please refer to [`AeroSync/README.md`](AeroSync/README.md) for full architecture details and algorithm breakdowns.
